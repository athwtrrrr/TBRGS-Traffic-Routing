# AI Search Algorithms & Traffic Route Guidance System

This repository contains two independent projects completed for **COS30019 – Introduction to Artificial Intelligence**.

| Folder | Project | Description |
|--------|---------|-------------|
| `2A/` | Classical Search Algorithms | Implementations of DFS, BFS, UCS, A*, GBFS, IDA*, and multi‑goal search on graph problems. |
| `2B/` | TBRGS – Traffic‑Based Route Guidance System | Desktop app that predicts traffic flow using LSTM/GRU/Transformer and recommends top‑5 shortest travel‑time routes with a PyQt5 + OpenStreetMap GUI. |
